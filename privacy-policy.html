Overview

PollyGlot is built to provide translation features with minimal data collection. This page explains what data may be processed, why it is used, and how long it is retained.

Data processed for translation

When you request a translation, the text you submit and selected language settings are sent to the translation API provider in order to generate results. This processing is required to provide core functionality. Translation requests may include temporary metadata such as request time and IP-derived rate-limit counters for abuse protection.

Local storage and settings

PollyGlot stores settings, translation history, and favorites in your browser local storage so your preferences persist between sessions. You can clear this data at any time from your browser or by using in-app controls. Local storage data is not shared with third parties by default.

Security and retention

The service applies input validation and request throttling to reduce abuse risk. Server logs may contain operational error information for debugging and reliability. We aim to keep retained operational data limited to what is necessary for security and uptime.

Contact

For privacy requests, contact privacy@pollyglot.app.
